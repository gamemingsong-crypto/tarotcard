# 🔮 บอทดูดวงไพ่ทาโร่ สำหรับ Discord

บอทเปิดไพ่ทาโร่ครบ 78 ใบ ให้คนในเซิร์ฟเวอร์ดูดวงรายวัน/รายเดือน แยกตามหมวด
(การเงิน / การงาน / ความรัก / สุขภาพ) และเปิดไพ่สุ่มถามคำถามได้ 1, 3, 5, หรือ 10 ใบ

## คำสั่งที่ใช้ได้

| คำสั่ง | คำอธิบาย |
|---|---|
| `/ดวง` | เลือกช่วงเวลา (รายวัน/รายเดือน) และหมวดหมู่ (ภาพรวม/การเงิน/การงาน/ความรัก/สุขภาพ) — ดวงเดิมจะไม่เปลี่ยนถ้าเรียกซ้ำในวัน/เดือนเดียวกัน |
| `/เปิดไพ่` | สุ่มเปิดไพ่ 1 / 3 / 5 / 10 ใบ พร้อมใส่คำถามได้ (ไม่บังคับ) — สุ่มใหม่ทุกครั้ง |
| `/วิธีใช้` | แสดงคำแนะนำการใช้งานบอท |

---

## ขั้นตอนติดตั้ง

### 1. สร้างแอปพลิเคชันและบอทใน Discord Developer Portal
1. ไปที่ https://discord.com/developers/applications แล้วกด **New Application** ตั้งชื่อบอท
2. ไปที่แท็บ **Bot** (ด้านซ้าย) กด **Reset Token** เพื่อรับ token ของบอท — เก็บไว้ให้ดี ห้ามเผยแพร่ที่ไหน
3. ยังอยู่ในแท็บ Bot ไม่ต้องเปิด privileged intent ใดๆ เพิ่ม (บอทนี้ใช้แค่ slash command ไม่ได้อ่านข้อความในแชท)

### 2. สร้างลิงก์เชิญบอทเข้าเซิร์ฟเวอร์
1. ไปที่แท็บ **OAuth2 > URL Generator**
2. เลือก scope: `bot` และ `applications.commands`
3. เลือก Bot Permissions: `Send Messages`, `Embed Links`, `Use Slash Commands`, `Read Message History`
4. คัดลอกลิงก์ที่ได้ แล้วเปิดในเบราว์เซอร์เพื่อเชิญบอทเข้าเซิร์ฟเวอร์ของคุณ

### 3. ติดตั้งโปรแกรมบนเครื่อง (ต้องมี Python 3.9 ขึ้นไป)
```bash
pip install -r requirements.txt
```

### 4. ตั้งค่า Token
คัดลอกไฟล์ `.env.example` เป็นไฟล์ชื่อ `.env` แล้วใส่ค่า token ที่ได้จากขั้นตอนที่ 1:
```
DISCORD_TOKEN=วางtokenของคุณตรงนี้
```
ถ้าต้องการทดสอบให้ slash command ขึ้นทันที (ไม่ต้องรอ) ให้ใส่ `GUILD_ID` เป็น ID ของเซิร์ฟเวอร์ทดสอบด้วย
(เปิด Developer Mode ใน Discord แล้วคลิกขวาที่ไอคอนเซิร์ฟเวอร์ > Copy Server ID)

### 5. รันบอท
```bash
python bot.py
```
เมื่อเห็นข้อความ `✅ Logged in as ... — พร้อมดูดวงแล้ว!` แปลว่าใช้งานได้แล้ว
ลองพิมพ์ `/ดวง` หรือ `/เปิดไพ่` ในเซิร์ฟเวอร์ของคุณได้เลย

> หมายเหตุ: ถ้าไม่ได้ใส่ `GUILD_ID` คำสั่ง slash command แบบ global อาจใช้เวลาถึง ~1 ชั่วโมง
> กว่าจะปรากฏครบในทุกเซิร์ฟเวอร์ (ครั้งแรกที่รันเท่านั้น หลังจากนั้นจะขึ้นทันที)

## โครงสร้างไฟล์
```
├── bot.py              # โค้ดหลักของบอท + slash commands
├── tarot_data.py        # ฐานข้อมูลไพ่ทาโร่ 78 ใบ + ฟังก์ชันสุ่ม/คำทำนาย
├── requirements.txt     # รายชื่อ library ที่ต้องติดตั้ง
├── .env.example         # ตัวอย่างไฟล์ตั้งค่า (คัดลอกเป็น .env)
└── data/
    └── daily_cache.json # (สร้างอัตโนมัติ) เก็บดวงรายวัน/รายเดือนของแต่ละคน
```

## ถ้าอยากรันแบบ 24 ชั่วโมง (โฮสต์ต่อเนื่อง)
โค้ดชุดนี้รันได้บนบริการ hosting ทั่วไปที่รองรับ Python bot แบบ long-running process เช่น
Railway, Render, VPS ส่วนตัว หรือ Raspberry Pi ที่บ้าน — ไม่แนะนำ hosting แบบ serverless
เพราะบอท Discord ต้องเปิดการเชื่อมต่อ (WebSocket) ค้างไว้ตลอดเวลา

## ปรับแต่งเพิ่มเติมได้ง่ายๆ
- อยากเปลี่ยนเปอร์เซ็นต์โอกาสไพ่กลับหัว → แก้ค่า `REVERSED_CHANCE` ใน `tarot_data.py`
- อยากเพิ่ม/แก้คำทำนายหรือคำแนะนำ → แก้ที่ dict `CATEGORY_INFO`, `ADVICE`, `ADVICE_GENERAL` ใน `tarot_data.py`
- อยากเพิ่มหมวดใหม่ (เช่น "การเรียน") → เพิ่มใน `CATEGORY_INFO` และ `ADVICE` แล้วเพิ่ม choice ในคำสั่ง `/ดวง` ที่ `bot.py`
